# Slim Dial — Design Notes

Personal Connect IQ watch face for D2 Mach 2. Visual source is two dial
photos, not a store-ready Hermès product.

## References

- `reference/hermes.png` — high-power mood: 1331×1182 RGB, ~2.0 MB. Product
  photo of a white opaline dial, offset seconds subdial at 6, sunburst inner
  disc, case, lugs, crown, strap, “SWISS MADE”. **Do not blit this.** Crop
  conceptually to the dial only; the D2 already has a physical bezel.
- `reference/hermes-dark.png` — always-on mood: 1254×1254 RGB, ~534 KB.
  Line-art of the same layout on black. Still too big and too lit to use as
  a resource. Use as the AOD stroke language.

Neither image has hands. Hands are always drawn in code.

## Platform constraints

- App type: `watchface` (this repo). Strength Coach stays `watch-app`.
- Screen: 454×454 AMOLED, 16 bpp.
- Heap: **128 KB**. Fullscreen buffer ~403 KB. Two of those do not exist.
- No `BufferedBitmap` for the full dial unless it is a tiny palette and
  measured under the heap. Start with zero bitmaps.
- AMOLED always-on (API 5.2 `System.getDisplayMode()`):
  - `DISPLAY_MODE_HIGH_POWER` — wrist up, ~10 s, 1 Hz updates.
  - `DISPLAY_MODE_LOW_POWER` — AOD, once per minute.
  - At most ~10% of pixels (or luminance on newer AMOLED) may be lit.
  - No pixel may stay on longer than three minute-updates. Shift the whole
    drawing 1 px on a 5-step orbit (`AnalogGeometry.burnInShift`).
  - Violating either rule blanks the screen until high power.
  - `onPartialUpdate` is a MIP seconds trick. D2 Mach 2 is AMOLED; do not
    rely on it for the live seconds hand.
- Simulator: File → View Screen Heat Map.

## Layout (dial only)

All radii are fractions of half the short axis (227 px on D2 Mach 2).

| Element | Ratio | Notes |
|---|---|---|
| Inner disc | 0.60 | Flat fill. No sunburst bitmap. |
| Chapter ring | 0.62 | 1 px stroke |
| Minute ticks | 0.64–0.68 | Skip 5-minute marks; hour marks are longer |
| Hour ticks | 0.64–0.70 | 12 marks |
| Numeral ring | 0.84 | Upright labels, not rotated |
| Subdial center Y | +0.38 from main center | On the 6 o’clock axis |
| Subdial radius | 0.22 | Lives on the inner disc, overlaps 6 |
| Main arbor | 0.018 | |
| Sub arbor | 0.010 | |

Numerals 1–12 are equally spaced 30°. They stay **upright** (en-plein),
never tangent to the circle. 10 / 11 / 12 are two-glyph clusters centered
on their hour point.

Seconds belong only to the subdial, and only in high power. AOD has no
seconds hand and no subdial.

## Color

High power:

- Dial field `#F4F1EA`
- Inner disc `#E4E0D8`
- Subdial `#DCD8D0`
- Strokes, numerals, hands `#111111`

Always-on:

- Field `#000000` only. Any non-black pixel counts as “on”.
- Strokes `#E8E0D0` (cream), 1 px
- 12 / 3 / 9 only; no 6, no subdial, no minute track

Do not dim the high-power drawing for AOD. It is a different drawing.

## Hands

Thin baton polygons, generated by `AnalogGeometry.handPolygon`.

- Hour: length 0.38, width 0.018, small tail
- Minute: length 0.55, width 0.012
- Seconds (subdial, high power only): length 0.18, width 0.006

No hands in the reference PNGs, so weight should match the numeral stems.

## Numerals

This is the actual product identity. See `docs/NUMERALS.md`. Draw as
Monkey C strokes in `HermesNumerals.mc`. Do not drop in a generic TTF —
the 8 is two stacked circles and will never come from a Latin text font.

Placeholder `FONT_TINY` in the scaffold is not the look.

## Memory policy

- No PNG resources except the launcher icon SVG.
- No fullscreen buffer, no Monkey Motion, no layers.
- Geometry is const floats + a few polygons per frame.
- Fail the unit test if helper code grows the heap by 16 KB.

## Out of scope for v1

- Complications (HR, steps, next workout)
- Settings / colorways
- Publishing to the Connect IQ Store under a Hermès name
- Sharing code or Storage with Strength Coach
